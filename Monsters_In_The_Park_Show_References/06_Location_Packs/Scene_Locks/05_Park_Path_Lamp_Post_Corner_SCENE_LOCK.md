# Park Path / Lamp Post Corner – Scene Lock

## Canon Name
Park Path / Lamp Post Corner

## Canon Number
5

## Keeper Status
Approved keeper.
Use the final Park Path / Lamp Post Corner technical sheet as the visual source of truth for layout, prop relationships, zone logic, and styling.

## Purpose
Recurring park path junction used for arrivals, exits, crossroads, decision moments, sign gags, and direction-based staging.

## Core Layout
- Main path enters from foreground center.
- Path splits into a soft Y-shape as it moves away from camera.
- Left side contains bench nook, lamp post, tree, shrubs, and low fence.
- Right side contains bulletin board, trash can, signpost cluster, shrubs, and low fence.
- Cobblestone curbs define the path edge and must remain consistent.
- Fence follows the rounded garden beds on both sides.
- Keep the center path open for character movement and clean staging.

## Fixed Prop Positions

### Left Side
- Bench sits inside the left garden nook, set back from the cobblestone curb.
- Bench faces toward camera / path.
- Lamp post sits in the front-right area of the bench.
- Lamp post base starts approximately 3 in off the cobblestone curb.
- Bench front-left corner is approximately 3 ft from the lamp post.
- Tree anchors the far-left background behind the bench.
- Shrubs surround the bench and tree.
- Low black fence wraps the left garden bed.

### Right Side
- Bulletin board sits inside the right garden bed.
- Bulletin board is perpendicular to the walkway in top-down view.
- Trash can sits near the bulletin board, closer to the inner path edge.
- Signpost cluster sits farther right, inside the right garden bed.
- Signpost cluster has four signs:
  - Playground
  - Fountain
  - Concessions
  - Restrooms
- Low black fence wraps the right garden bed.
- Right-side fence, bulletin board, trash can, and signpost cluster must match across wide, top-down, prop-callout, and performance-zone views.

## Relative Measurements
- Lamp post base offset from cobblestone curb: approx. 3 in
- Bench front-left corner to lamp post: approx. 3 ft
- Bench setback from cobblestone curb: approx. 2 ft
- Lamp post to path center: approx. 6 ft
- Trash can to bulletin board: approx. 5 ft
- Foreground path width at B zone: approx. 22 ft
- Depth to back / upstage area: approx. 18–20 ft

## Measurement Method
- Lamp post base offset is measured from the outer edge of the lamp post base to the nearest cobblestone curb edge.
- Bench front-left corner to lamp post is measured from the front-left outer bench corner to the center of the lamp post base.
- Bench setback is measured from the nearest front curb edge to the nearest front bench footprint edge.
- Lamp post to path center is measured from lamp post base center to the approximate centerline of the foreground path.
- Trash can to bulletin board is measured from trash can base center to the nearest outer edge of the bulletin board structure.
- Foreground path width is measured curb-to-curb at the primary B-zone staging area.
- Depth to back is measured from the foreground staging edge to the upstage midpoint of the path split.
- Use ft and in notation.
- Use "approx." when visually inferred.

### Top-Down Plan
- Shows the left bench nook and right bulletin-board / signpost nook clearly.
- Must preserve the Y-shaped split.
- Bulletin board stays perpendicular to the walkway.
- Signpost cluster remains farther right than the bulletin board.
- Lamp post remains tight to the curb and congruent with the front-elevation layout.

### Close / Performance View
- Pushes toward the bench / lamp post area or center path action without moving props.
- Signpost cluster may crop naturally but must not relocate.
- Bulletin board and trash can remain logically placed when visible.
- Do not re-stage props for convenience.

## Character Performance Zones

### A – Attractor Character Interaction Area
Near the bench and lamp post on the left.
Use for character conversations, waiting, discoveries, or emotional beats.

### B – Main Meeting / Space Action Zone
Open foreground path area.
Use for group action, arrivals, and movement.

### C – Right Side Interaction Zone
Near the bulletin board and sign cluster.
Use for reading signs, getting lost, arguments about direction, or object interaction.

### D – Upstage Chilling Zone
Far background midpoint.

### E – Lively Eye-Line Zone
Center path pull.
Leads the eye toward the first attractor and supports movement into the scene.
