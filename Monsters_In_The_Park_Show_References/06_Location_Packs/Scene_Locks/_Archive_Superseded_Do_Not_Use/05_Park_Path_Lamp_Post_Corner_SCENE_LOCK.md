# Park Path / Lamp Post Corner – Scene Lock

## Canon Name
Park Path / Lamp Post Corner

## Purpose
Recurring park path junction used for arrivals, exits, crossroads, decision moments, sign gags, and direction-based staging.

## Core Layout
- Main path enters from foreground center.
- Path splits into a soft Y-shape as it moves away from camera.
- Left side contains bench nook, lamp post, tree, shrubs, and low fence.
- Right side contains bulletin board, trash can, signpost cluster, shrubs, and low fence.
- Cobblestone curbs define the path edge and must remain consistent.
- Fence follows the rounded garden beds on both sides.
- Keep the center path open for character movement and clean staging.

## Fixed Prop Positions

### Left Side
- Bench sits inside the left garden nook, set back from the cobblestone curb.
- Bench faces toward camera / path.
- Lamp post sits in the front-right area of the bench.
- Lamp post base starts approximately 3 in off the cobblestone curb.
- Bench front-left corner is approximately 3 ft from the lamp post.
- Tree anchors the far-left background behind the bench.
- Shrubs surround the bench and tree.
- Low black fence wraps the left garden bed.

### Right Side
- Bulletin board sits inside the right garden bed.
- Bulletin board is perpendicular to the walkway in top-down view.
- Trash can sits near the bulletin board, closer to the inner path edge.
- Signpost cluster sits farther right, inside the right garden bed.
- Signpost cluster has four signs:
  - Playground
  - Fountain
  - Concessions
  - Restrooms
- Low black fence wraps the right garden bed.
- Right-side fence, bulletin board, trash can, and signpost cluster must match across wide, medium, close, technical sheet, and performance-zone views.

## Relative Measurements
- Lamp post base offset from cobblestone curb: 3 in
- Bench front-left corner to lamp post: 3 ft
- Bench setback from cobblestone curb: 2 ft
- Lamp post to path center: 6 ft
- Trash can to bulletin board: 5 ft
- Foreground path width at B zone: 22 ft
- Depth to back / upstage area: 18–20 ft

## Camera Views

### Wide Plate
- Shows the full Y-shaped path split.
- Shows bench, lamp post, bulletin board, trash can, signpost cluster, fences, and both curbs.
- Use as the master layout reference.

### Medium Plate
- Pushes in without moving props.
- Signpost cluster may be partially cropped but must not relocate.
- Bench and lamp post stay locked relative to the curb.
- Bulletin board stays perpendicular to the walkway.

### Close Plate
- Pushes further toward the bench / lamp post area.
- Signpost cluster can be removed by crop.
- Keep bulletin board / trash can only if naturally visible from original framing.
- Do not re-stage props for convenience.

## Character Performance Zones

### A – Attractor Character Interaction Area
Near bench and lamp post on left. Use for character conversations, waiting, discoveries, or emotional beats.

### B – Main Meeting / Space Action Zone
Open foreground path area. Primary staging zone for group action, arrivals, and movement.

### C – Right Side Interaction Zone
Near bulletin board and sign cluster. Use for reading signs, getting lost, arguments about direction, or object interaction.

### D – Upstage Chilling Zone
Far background midpoint. Use for secondary action, distant entrances, or small visual jokes.

### E – Lively Eye-Line Zone
Center path pull. Leads the eye toward the first attractor and supports movement into the scene.

## Do Not Move
- Bench
- Lamp post
- Bulletin board
- Trash can
- Signpost cluster
- Tree
- Curb curve
- Path split
- Fence curves
- Shrub massing

## Style Lock
- Muted watercolor
- Dusty sage greens
- Warm beige parchment
- Soft ink lines
- Low contrast
- Light transparent foliage
- Gentle storybook texture
- No high saturation
- No hard poster-like outlines
- No glossy rendering

## Generation Rules
- Do not redesign the layout.
- Do not move props between shots.
- Do not change the Y-shaped path split.
- Do not make the lamp post float away from the curb.
- Do not rotate the bulletin board parallel to the walkway.
- Do not reduce the signpost cluster to three signs.
- Do not alter the bench / lamp relationship.
- Push in by cropping from the wide plate, not by rebuilding the scene.
- Characters occupy open staging zones, not prop locations.
