# Location Technical Sheet – Layout Lock

## Purpose
Use this layout lock to reproduce the exact same 9:16 vertical technical sheet structure for every locked Monsters in the Park Show location.

This file controls page format, section order, visual hierarchy, labeling, style, and consistency rules. Each location can change its scene content, but the sheet system should stay the same.

## Canon Page Format
- Format: 9:16 vertical portrait
- Recommended size: 1024 x 1536 px or higher
- Background: warm parchment paper texture
- Overall style: muted watercolor storybook technical sheet
- Border: thin blue frame around main page content
- Section dividers: thin blue horizontal rules
- Typography color: deep navy blue
- Accent lines: muted blue
- Use clear numbered sections

## Title System
Top title block must use this structure:

```text
[LOCATION NUMBER] [CANON LOCATION NAME]
LOCATION TECHNICAL SHEET
```

Example:

```text
1 PARK PATH / LAMP POST CORNER
LOCATION TECHNICAL SHEET
```

Title rules:
- Large navy uppercase location name
- Small circled number before location name
- Subtitle centered below
- Thin horizontal blue decorative lines on both sides of subtitle
- Do not use “stylized” in the title
- Do not rename locations casually
- Use the canon location name from the reference packs

## Required Page Sections

### 1. Front Elevation / Camera View
Purpose:
- Shows the main locked front-facing view of the location.
- Functions as the production-facing reference image.

Placement:
- Top large image panel under title.
- Full width inside page frame.

Rules:
- Use the approved wide plate as the source.
- Do not redesign the scene.
- Do not move props.
- Keep major props in their locked positions.
- Keep camera-facing orientation consistent.
- Use this as the main visual truth for the location.

Label:

```text
1. FRONT ELEVATION / CAMERA VIEW
```

### 2. Top-Down Plan
Purpose:
- Shows the location as a simplified top-down or angled top-down plan.
- Clarifies prop placement, path geometry, staging zones, and spatial logic.

Placement:
- Second full-width panel below front elevation.

Rules:
- Must match the front elevation layout.
- Props must occupy the same logical positions.
- Do not invent missing props.
- Do not add duplicate props.
- Use angled top-down if pure overhead makes objects unreadable.
- Important vertical items, like lamp posts, may be shown with some height so they read clearly.
- Keep path edges, curb curves, fence lines, tree masses, and building/fountain footprints consistent.

Label:

```text
2. TOP-DOWN PLAN
```

### 3. Prop Callouts
Purpose:
- Isolates the location’s fixed recurring props.
- Gives production a quick prop checklist.

Placement:
- Third panel, horizontal row.

Rules:
- Use simple object cutouts on parchment.
- Separate props with thin dotted blue divider lines.
- Label each prop in uppercase navy text.
- Use consistent prop names across all sheets.
- Use only props that are locked for that location.
- Do not change prop design between the scene view and callout row.

Label:

```text
3. PROP CALLOUTS
```

Prop label examples:
- BENCH
- LAMP POST
- TRASH CAN
- BULLETIN BOARD
- SIGNPOST CLUSTER
- FENCE LINE
- COBBLESTONE CURB

### 4. Character Performance Zones
Purpose:
- Shows where characters can safely stage, interact, pause, enter, or perform.
- Prevents characters from blocking key props or drifting into unusable space.

Placement:
- Fourth major panel below prop callouts.
- Large image on left.
- Zone legend column on right.

Rules:
- Use the same scene layout as the front elevation.
- Overlay simple dashed shapes and letter markers.
- Do not place zone letters on unrelated props.
- Each letter must correspond clearly to the legend.
- Keep open path space for action.
- Keep props visible and unblocked where needed.

Label:

```text
4. CHARACTER PERFORMANCE ZONES
```

Standard zone system:
- A = Attractor Character Interaction Area
- B = Main Meeting / Space Action Zone
- C = Right Side Interaction Zone
- D = Upstage Chilling Zone
- E = Lively Eye-Line Zone

Zone legend format:

```text
A  ATTRACTOR CHARACTER INTERACTION AREA
Near the bench and lamp post on the left

B  MAIN MEETING / SPACE ACTION ZONE
Open foreground area for primary staging

C  RIGHT SIDE INTERACTION ZONE
Near the bulletin board and sign cluster

D  UPSTAGE CHILLING ZONE
At the park’s midpoint to the park beyond the little skyline

E  LIVELY EYE-LINE ZONE
Leading the eye center path toward the first zone
```

### 5. Bottom Production Notes
Purpose:
- Locks what cannot move, where camera can push in, and key measurements.

Placement:
- Bottom row split into three columns:
  - 5A. Do Not Move
  - 5B. Camera Can Push In Here
  - 5C. Measurements

Rules:
- Keep all three columns aligned.
- Use short bullets.
- Use ft and in, not “units,” when measurements are known.
- If a measurement is approximate, use “approx.”
- Measurements must match the scene lock MD.
- Do not add speculative measurements unless they help production consistency.

Labels:

```text
5A. DO NOT MOVE
5B. CAMERA CAN PUSH IN HERE
5C. MEASUREMENTS
```

## Visual Style Lock
Use the same visual treatment across all location technical sheets.

Style:
- Muted watercolor
- Dusty sage greens
- Warm beige parchment
- Soft ink lines
- Low contrast
- Light transparent foliage
- Gentle storybook texture
- Slight handmade imperfection
- Readable but not poster-sharp

Avoid:
- High saturation
- Hard black outlines
- Glossy rendering
- Overly crisp infographic look
- Dense graphic foliage
- Heavy shadows
- Over-warmed orange paper
- Modern vector-flat styling
- Photorealism

## Color System
Core palette:
- Deep navy blue for headings and section labels
- Muted blue for lines and borders
- Dusty sage green for foliage
- Moss green for darker plants
- Warm sand for path and parchment
- Soft umber for wood
- Tree bark brown
- Stone gray for curb and stone elements

Color rules:
- Keep greens dusty, not neon.
- Keep yellows soft, not golden or saturated.
- Keep reds and oranges muted.
- Keep shadows soft.
- Keep paper texture visible.
- Use lower contrast than a poster or game UI sheet.

## Layout Consistency Rules
Every location technical sheet must preserve:
- 9:16 vertical page
- Same title hierarchy
- Same section order
- Same numbered section labels
- Same blue border and divider system
- Same prop callout row format
- Same performance zone legend style
- Same bottom three-column note system
- Same watercolor tone

Do not:
- Change section order
- Replace top-down plan with a duplicate camera view
- Add unrelated reference images
- Move technical notes into the wrong section
- Rename zones between sheets
- Switch between “reference pack” and “technical sheet” on the same document type

## Scene Content Rules
For each location:
- Start with the approved wide plate.
- Build the front elevation / camera view from that approved wide plate.
- Build the top-down plan from the same layout logic.
- Pull prop callouts from locked recurring props.
- Build character zones around open performance areas.
- Write measurements from known scene lock data.
- Add missing measurements only after confirming they make spatial sense.

## Cropping Rules
When creating medium or close views from a location:
- Push in from the approved wide plate.
- Do not rebuild the scene from scratch.
- Do not move props to keep them visible.
- Cropping can remove props naturally.
- Cropping must not relocate props.
- Negative space for characters is intentional. Preserve it.

## Prop Continuity Rules
Props must keep:
- Same relative placement
- Same scale
- Same color family
- Same orientation
- Same relationship to curb, path, fence, trees, or buildings

If a prop appears in multiple panels, it must match:
- Front elevation / camera view
- Top-down plan
- Prop callout
- Character performance zones
- Scene lock MD
